## 照片要求

### 尺寸建议
- **学校照片**: 建议 800x600px 或更高
- **活动照片**: 建议 1200x800px 或更高
- **Gallery照片**: 建议 1200x800px 或更高
- **二维码**: 建议 500x500px

### 格式
- 支持格式: JPG, PNG
- 建议使用 JPG 格式以减小文件大小
- 图片质量: 80-90%

### 命名规范
- 使用小写字母和连字符
- 避免使用空格和特殊字符
- 使用描述性的文件名

## 上传照片步骤

1. 将照片放入对应的文件夹
2. 确保文件名与代码中引用的名称一致
3. 如果需要添加新照片，请更新相应的HTML/JS代码
