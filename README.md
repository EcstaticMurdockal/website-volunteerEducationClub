# 深圳中学支教社官网

一个现代化、精美的支教社团官方网站，展示社团活动、历程和精彩瞬间。

## 功能特点

### 🏠 Home（首页）
- **精美的Hero区域**：渐变背景配合动画效果
- **宣传标语**：体现支教情怀的自然文案
- **互动地图**：使用Leaflet地图库展示支教学校位置
  - 点击地图标记可查看学校环境照片
  - 支持5所合作学校的展示
- **时间线设计**：展示社团2020-2024年的发展历程
  - 交互式动画效果
  - 悬停放大效果

### 🎯 Activities（活动）
- **社团活动展示**：4个核心活动类型
  - 课程支教
  - 线上教学
  - 素质拓展
  - 图书捐赠
- **招募要求**：展示需要的志愿者特质
- **趣味问卷系统**：
  - 10道精心设计的问题
  - 4种支教人格类型（领航者、心灵导师、创新先锋、坚实后盾）
  - 自动分析天赋优势、提升方向和建议
  - 类似MBTI的有趣测试体验

### 🖼️ Gallery（画廊）
- **分类展示**：PPT作品、宣传视频、活动照片
- **标签筛选**：快速切换不同类型的内容
- **点赞功能**：
  - 实时点赞/取消点赞
  - 使用localStorage保存点赞状态
  - 动画效果增强互动体验
- **卡片式布局**：响应式网格设计

### 📞 Contact（联系方式）
- B站主页链接
- 微信公众号二维码展示
- 加入社团的引导信息

## 技术栈

- **HTML5**：语义化标签
- **CSS3**：
  - CSS变量
  - Flexbox & Grid布局
  - 动画和过渡效果
  - 响应式设计
- **JavaScript (ES6+)**：
  - 原生JavaScript，无框架依赖
  - 模块化代码结构
  - LocalStorage数据持久化
- **Leaflet.js**：交互式地图功能

## 使用方法

### 1. 直接打开
双击 `index.html` 文件即可在浏览器中打开网站。

### 2. 使用本地服务器（推荐）
为了获得最佳体验，建议使用本地服务器：

```bash
# 使用Python
python -m http.server 8000

# 或使用Node.js的http-server
npx http-server
```

然后在浏览器中访问 `http://localhost:8000`

## 自定义内容

### 修改支教学校信息
编辑 `script.js` 中的 `schools` 数组：

```javascript
const schools = [
    {
        name: '学校名称',
        coords: [纬度, 经度],
        images: ['图片URL1', '图片URL2']
    },
    // 添加更多学校...
];
```

### 修改时间线内容
编辑 `index.html` 中的 `.timeline-item` 部分。

### 修改Gallery内容
编辑 `script.js` 中的 `galleryData` 数组：

```javascript
const galleryData = [
    {
        id: 1,
        title: '标题',
        description: '描述',
        category: 'ppt', // 或 'video', 'photo'
        image: '图片URL',
        likes: 初始点赞数
    },
    // 添加更多内容...
];
```

### 修改问卷题目
编辑 `script.js` 中的 `quizData` 数组和 `quizResults` 对象。

### 更换配色方案
编辑 `styles.css` 中的CSS变量：

```css
:root {
    --primary-color: #4a90e2;    /* 主色调 */
    --secondary-color: #f39c12;  /* 次要色 */
    --accent-color: #e74c3c;     /* 强调色 */
    /* ... */
}
```
